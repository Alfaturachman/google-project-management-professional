# Learning About Careers in Project Management

## From certificate to career success

**Permintaan Pasar dan Industri**

- Peran project management sangat diminati, dengan perkiraan kebutuhan sebanyak 87.7 juta peran sejenis (*project management-aligned roles*) pada tahun 2027.
- Industri dengan pertumbuhan signifikan meliputi manufacturing, construction, information services, finance, utilities, serta oil and gas.

**Jenis Jabatan Project Management**

- Jabatan project manager sering menyertakan kualifikasi spesifik industri, seperti "construction project manager" atau "IT project manager", tetapi core skills yang dimiliki tetap transferable.
- Jabatan alternatif yang terkait antara lain operations manager, program manager, project coordinator, dan berbagai peran asisten.

**Jalur Karier dan Peluang**

- Internships memberikan pengalaman praktis (*hands-on experience*) dan peluang networking yang berpotensi mengarah ke peran project management full-time.
- Contract work menawarkan fleksibilitas dan exposure terhadap berbagai perusahaan serta jenis project, membantu menentukan kecocokan terbaik, dan bisa berujung pada posisi permanen.

## Explore project management roles

Project management mencakup banyak posisi di berbagai industri. Sertifikasi ini membekali skills yang memenuhi syarat untuk berbagai jabatan, mulai dari entry-level hingga peran senior program management.

### Entry-level project management roles

Posisi entry-level menjadi peluang untuk mempelajari cara kerja dan pengelolaan project di suatu perusahaan. Beberapa posisinya antara lain:

- **Junior Project Manager**: menjalankan semua aspek pekerjaan project manager bersama profesional yang lebih berpengalaman.
- **Project Administrator**: membantu tim project dalam tugas administratif.
- **Project/Program Assistant**: mendukung anggota tim dan memberikan bantuan administratif; dapat melakukan riset, membuat training documents, atau tugas lain yang diberikan oleh program leaders.
- **Project/Program Coordinator**: terlibat dalam pekerjaan project secara langsung dan tugas administratif; bekerja di bawah project manager untuk memastikan project selesai tepat waktu dan dalam budget.
- **Project Support Specialist**: bekerja bersama project manager dan anggota tim untuk mengawasi project yang ditugaskan; dapat juga bertanggung jawab melatih dan mengembangkan karyawan.

### Traditional project management roles

Setelah memiliki pengalaman di posisi entry-level, dapat mengeksplorasi peran tradisional berikut:

- **Project Manager**: bertanggung jawab atas initiating, planning, executing, monitoring, dan closing sebuah project. Termasuk jabatan spesifik industri seperti IT project manager, construction project manager, atau engineering project manager, dengan skills yang transferable antar industri.
- **Project Analyst**: memajukan project dengan berbagi informasi, memberikan dukungan melalui data analysis, serta berkontribusi pada strategy dan performance.
- **Project Leader/Director**: menggerakkan decision-making inti dan menentukan arah project; biasanya menguasai produk atau deliverable.
- **Project Controller**: terutama bertanggung jawab atas project planning; umum ditemukan di industri engineering dan construction.
- **Technical Project Manager**: melakukan project planning dan management untuk tujuan tertentu dalam perusahaan; memastikan project memenuhi requirements dalam timeframe dan budget yang ditentukan.
- **Project Management Office (PMO) Analyst**: mengelola progres project yang kompleks agar eksekusi dan penyelesaiannya tepat waktu.

### Program and portfolio management roles

- Project manager menangani manajemen project sehari-hari, mengantar project dari awal hingga akhir, dan menerapkan tools, techniques, serta processes yang sesuai agar project sukses, tepat waktu, dan dalam budget.
- **Program** adalah kumpulan dari beberapa project. **Program manager** bertanggung jawab mengelola banyak project sekaligus.
- Di Google, project managers disebut program managers karena mengelola beberapa project secara bersamaan.
- Setelah berhasil mengelola project dan siap untuk tanggung jawab yang lebih besar, jenjang selanjutnya adalah **Senior Program Manager** atau **Portfolio Manager**.
- **Portfolio** adalah kumpulan project dan program di seluruh organisasi. **Portfolio manager** bertanggung jawab atas portfolio project atau program untuk satu klien.
- Perjalanan karier yang umum: project manager → program manager → portfolio manager.
- Meskipun memiliki jenis dan tingkat tanggung jawab yang berbeda, project, program, dan portfolio managers semuanya adalah project managers.

**Program managers**:

- Mengelola sekelompok project yang saling terkait atau serupa serta menangani koordinasi antar project tersebut.
- Memfasilitasi komunikasi yang efektif antar project manager dan memberikan dukungan bila diperlukan.
- Membantu membuat dan mengelola long-term goals organisasi.

**Portfolio managers**:

- Bertanggung jawab mengelola sekelompok program terkait dalam organisasi yang sama.
- Mengoordinasikan berbagai program agar tetap on track dan organisasi memenuhi strategic initiatives-nya.
- Memandang seluruh project dan program dalam organisasi serta memprioritaskan pekerjaan sesuai kebutuhan.

### Operational management roles

Peran ini memberi pengalaman lintas departemen serta kesempatan bekerja sama dengan rekan dan manajemen dari berbagai segmen bisnis. Elemen kunci project management — on budget dan on schedule — dapat diterapkan untuk menjalankan bisnis. Beberapa posisinya:

- **Operations Analyst**: mengelola dan mengoordinasikan riset, menyelidiki workflows, membuat business procedures, dan merekomendasikan perubahan untuk meningkatkan project dan perusahaan.
- **Operations Manager**: mengawasi strategic decision-making dan meluncurkan action plans berdasarkan laporan finansial, jadwal, dan sumber daya.
- **Chief Operating Officer (COO)**: bertanggung jawab mengawasi fungsi administratif dan operasional bisnis sehari-hari.

### Agile roles

Pendekatan *Agile project management* akan dibahas lebih dalam nanti. Beberapa posisi terkait:

- **Scrum Master**: mengoordinasikan dan memandu tim Scrum; memahami Agile framework dan Scrum serta mampu mengajarkan nilai dan prinsip Scrum kepada orang lain.
- **Product Owner**: mendorong arah pengembangan dan progres product.

### Industry-specific management roles

- Saat mencari pekerjaan, mungkin ditemui jabatan seperti "engineering project manager" atau "construction project manager".
- Skills yang dipelajari di satu industri dapat diterapkan ke industri lain. Contohnya, pengalaman sebagai software engineer dapat dikombinasikan dengan skills dari sertifikasi ini untuk posisi project manager di berbagai industri.
- Pengalaman bekerja dalam tim, menjalankan tugas on schedule dan on budget, serta pengetahuan project management memungkinkan perpindahan antar industri.

## Using buzzwords and skills in your job search

- **Buzzwords** adalah kata atau frasa yang populer pada periode tertentu atau di industri tertentu, misalnya *data-driven*, *team player*, dan *self-starter*.
- Gunakan buzzwords dan skills yang relevan untuk mencari pekerjaan dan untuk ditampilkan di resume agar dikenali recruiter dan hiring managers.

**Skills yang umum dicantumkan dalam job descriptions:**

- **Coordination**: mengarahkan orang dan tim agar bekerja sama. Contoh frasa: "coordination of efforts to achieve project deliverable" atau "coordinate internal resources to ensure successful project completion". Ini salah satu skills terpenting seorang project manager.
- **Organization**: kemampuan tetap fokus pada berbagai tugas. Contoh frasa: "solid organizational skills, including attention to detail and multitasking skills" atau "highly organized".
- **Leadership**: kemampuan memimpin sekelompok orang. Contoh frasa: "strong leadership qualities" atau "ability to lead". Ditunjukkan melalui effective planning, efficient task coordination, inspiring team members, dan key decision-making.

**Contoh job description "Project Manager":**

- Excellent time management, prioritization, and organizational skills
- Demonstrated ability to lead others
- Outstanding communication skills
- Successful track record in coordinating the work of internal and external teams to develop new products

**Contoh "Operations Associate"** (tidak menyebut "project manager" tetapi merupakan jenis project manager):

- Plan and organize team objectives and priorities
- Develop and execute reporting and process design
- Monitor daily operations and enhance processes to maximize efficiency
- Coordinate training plans

- Jangan mengabaikan posisi yang tidak menyertakan judul "Project Manager" — job description sering kali memuat pengalaman dan ekspektasi project management meskipun jabatannya berbeda.
- Sebagian besar job description terkait project management mensyaratkan kemampuan plan, organize, monitor, dan execute tasks.

**Buzzwords project management yang umum untuk resume:**

- Analytical, assertive, assessing outcomes, assessing progress, attention to detail
- Conflict resolution, collaborative, coordination, communication
- Development, evaluation, executing plans
- Financial analysis, impact assessment, leadership engagement
- Managing meetings, managing client expectations, managing conflicts, managing relationships with stakeholders, managing vendors, meeting deadlines, monitoring, multitasking
- Planning, prioritizing, problem-solving, process development, process improvement
- Project coordination, project implementation, project initialization, project planning, project reporting
- Quality control
- Risk assessment, risk management
- Solution development, strategic planning, strong interpersonal skills, strong verbal communication, strong written communication

**Key takeaway:**

- Project management adalah jalur karier dengan potensi yang besar; setiap langkah membangun kontribusi yang signifikan bagi perusahaan.
- **Transferable skills** adalah kemampuan yang dapat dipakai di berbagai pekerjaan dan jalur karier, dan sangat mungkin dimanfaatkan pada peran project management di berbagai industri.
- Jangan terhalang oleh syarat pengalaman saat melamar; banyak skills yang sudah dimiliki dapat diterjemahkan ke peran project management.

## Finding the perfect role

**Memahami Job Listings**

- Job listings sering memuat buzzwords seperti "data-driven", "team player", dan "self-starter" yang membantu mengidentifikasi kualitas yang dicari perusahaan.
- Project management dapat dicantumkan sebagai peran atau sebagai skill, sehingga memperluas rentang peluang kerja yang tersedia.

**Memperluas Peluang Kerja**

- Skills dari project management membuat seseorang memenuhi syarat untuk berbagai peran selain "Project Manager", seperti Operations Manager, Program Manager, atau Project Assistant.
- Job descriptions sering memuat tugas dan skills yang sejalan dengan project management meskipun judul jabatannya berbeda.

**Memanfaatkan Pengalaman dan Networking**

- Banyak peran, termasuk mengajar, melibatkan project management skills seperti planning, communication, dan budget management.
- Networking adalah alat penting dalam mencari kerja: membantu belajar, berbagi pengetahuan, dan membangun koneksi profesional yang relevan dengan karier project management.

## Gilbert: Project management skills in my role

**Peran dan Tanggung Jawab**

- Talent outreach melibatkan identifikasi dan dukungan terhadap kandidat yang mungkin tidak dipertimbangkan secara tradisional, serta membimbing mereka melalui proses wawancara.
- Project management skills seperti stakeholder communication, budget management, dan timeline coordination sangat penting terlepas dari jabatan spesifiknya.

**Transferable Skills dan Pengalaman**

- Skills yang dipelajari dari pekerjaan yang tidak berhubungan, seperti retail management, dapat diterjemahkan secara efektif ke peran project management.
- Menerapkan project management frameworks pada project pribadi atau profesional kecil membantu membangun confidence dan competence untuk project yang lebih besar dan kompleks.

**Saran untuk Calon Project Manager**

- Praktik adalah kunci untuk mengatasi imposter syndrome dan membangun kepercayaan diri terhadap project management skills.
- Mengambil langkah pertama dengan mengikuti course serta tidak takut gagal adalah hal yang penting.
- Mencari bantuan, bertanya, dan networking dengan para profesional di bidang ini dapat memberikan dukungan dan bimbingan yang berharga.

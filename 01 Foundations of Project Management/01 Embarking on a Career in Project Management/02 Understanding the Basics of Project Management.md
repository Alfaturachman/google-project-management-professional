# Understanding the Basics of Project Management

## What is project management?

**Pengertian Project**

- **Project** adalah upaya unik (*unique*) dan sementara (*temporary endeavor*) yang memiliki awal dan akhir yang jelas.
- Project bertujuan mencapai hasil spesifik melalui serangkaian tugas yang terkoordinasi.
- Project membutuhkan kolaborasi dan perencanaan yang cermat agar tetap sesuai jalur dan dalam batas budget.

**Pengertian Project Management**

- **Project management** adalah penerapan pengetahuan (*knowledge*), keterampilan (*skills*), alat (*tools*), dan teknik (*techniques*) untuk memenuhi project requirements dan mencapai hasil yang diinginkan.
- Project management memastikan project memberikan hasil yang diharapkan sesuai waktu dan budget, sekaligus menambah nilai (*value*) bagi bisnis.

**Contoh Nyata dan Pentingnya**

- Contoh: implementasi teknologi telehealth di sekolah melibatkan berbagai tugas seperti training, budgeting, dan komunikasi — semuanya dikelola melalui project management.
- Project management yang buruk menyebabkan kerugian finansial besar dan kegagalan project.
- Project management yang efektif sangat penting bagi kesuksesan organisasi.

**Peran di Google**

- Google mempekerjakan banyak project (program) managers untuk mengawasi beberapa project sekaligus agar operasional berjalan lancar.
- Project managers di Google, misalnya *responsible innovation program manager*, berkontribusi melalui planning, organizing, task management, budgeting, dan penyelarasan project dengan tujuan organisasi (*organizational goals*).

## What does a project manager do?

**Tanggung Jawab Utama Project Manager**

- **Planning & organizing**: mengumpulkan project requirements dan membuat project plans untuk menyelaraskan tim serta menentukan arah project.
- **Managing tasks**: mengoordinasikan pekerjaan anggota tim dan mengomunikasikan milestones penting agar semua pihak tetap terinformasi.

**Budgeting dan Cost Control**

- Mengawasi project budget dan mengendalikan biaya agar project tetap sehat secara finansial.
- Menyesuaikan rencana sesuai kebutuhan untuk menangani pengeluaran tak terduga dan perubahan selama project lifecycle.

**Menciptakan Value dan Variasi Kerja**

- Memastikan hasil project memberikan value bagi perusahaan, baik melalui layanan baru maupun perbaikan layanan yang sudah ada.
- Menggunakan berbagai tools, techniques, dan methodologies setiap hari, sehingga peran project manager bersifat dinamis dan bervariasi.

## Transferable project management skills

**Keterampilan Project Management dalam Kehidupan Sehari-hari**

- Skills seperti planning & organizing tugas, mengelola budget, dan mengendalikan biaya sudah dipakai dalam aktivitas seperti merencanakan acara kejutan atau mengoordinasikan pindahan.
- Mengelola jadwal karyawan di industri retail atau jasa melibatkan planning, organizing, dan memastikan cakupan kerja — semua itu sejalan dengan kemampuan project management.

**Memindahkan Skills ke Project Management**

- Banyak pengalaman hidup melibatkan manajemen banyak tugas sekaligus, mengoordinasikan resources, dan mengelola waktu — semuanya relevan dengan project management.
- Skills ini dapat ditonjolkan saat wawancara kerja untuk menunjukkan kemampuan time management, leadership, dan organizational.

**Mengembangkan Kemampuan Project Management**

- Mempelajari project management membantu mengasah dan memperluas skills agar mampu menangani project yang lebih besar dan kompleks.
- Course ini mendorong pembelajar untuk mengenali skills yang sudah dimiliki dan siap menerapkannya pada peran project management di masa depan.

## Path to becoming a project manager

**Perjalanan Pribadi dan Latar Belakang**

- Pembicara berbagi jalur non-tradisional menuju program management, termasuk berhenti dari SMA dan kuliah, belajar coding secara otodidak, serta menjalani delapan tahun dinas di Angkatan Darat.
- Pengalaman membangun aplikasi untuk perusahaan besar dan pemerintahan membawa mereka bergabung dengan Google sebagai program manager — menggabungkan kemampuan teknis dengan tanggung jawab manajemen yang baru.

**Peran dan Daya Tarik Program Management**

- Program management bervariasi tergantung tim, misalnya perbedaan antara Google Cloud dan YouTube, sehingga menawarkan pengalaman beragam di luar coding.
- Peran ini melibatkan koordinasi orang dan tugas untuk mencapai tujuan bersama, serta membutuhkan accountability, scheduling, dan keterampilan kolaborasi.

**Belajar dan Berkembang dalam Program Management**

- Pembicara menekankan belajar melalui pengalaman praktis dan mentoring, bukan hanya melalui pendidikan formal.
- Pengembangan diri, seperti mengelola jadwal dan memahami pendekatan orang lain, mendukung program management dan leadership yang efektif.
